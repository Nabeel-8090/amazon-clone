# Amazon Clone

A simple **Amazon Clone** built using **HTML & CSS**.  
This project is designed for **laptop screens only** and is not responsive for mobile devices.  

## Features
- Amazon-like homepage layout  
- Navigation bar and search bar  
- Product grid design  
- Footer section  

## Tech Stack
- HTML5  
- CSS3  

## Limitations
- Not responsive (works best on laptop view)  
- No functionality (static design only)  

## How to Use
Run the following command in the terminal to clone the repository:
```sh
git clone https://github.com/YOUR_USERNAME/amazon-clone.git
cd amazon-clone
```
Alternatively, download the ZIP file and extract it.
